# 🍸 OpenBars Israel

**OpenBars** היא פלטפורמת גילוי מקומות בילוי, ברים, מועדונים, פאבים ומסעדות בישראל בזמן אמת.
המערכת מציגה נתונים אמיתיים על גבי מפת ישראל חשוכה ואינטראקטיבית בעברית, תוך עמידה מלאה בגבולות הריבוניים של מדינת ישראל.

---

## ✨ תכונות עיקריות (Key Features)

- **מפה אינטראקטיבית חשוכה (Dark Mode)**: מבוססת Leaflet בעברית מלאה, עם הגבלת גבולות גזרה חמורה לשטח מדינת ישראל בלבד (ללא לבנון, עזה, ירדן או שטחי C).
- **מעל 4,400 מקומות מאומתים**: מאגר מורחב הכולל ברים, פאבים, מועדוני לילה, מסעדות, בתי קפה, ביסטרו, ודוכני אוכל ברחבי הארץ (חיפה, תל אביב, ירושלים, באר שבע, אשקלון, אשדוד, גוש דן, צפון ודרום).
- **מדד עומס חי (Live Crowdedness)**: חישוב עומס אלגוריתמי בזמן אמת (עמוס מאוד, עמוס, מתמלא, רגוע). מקומות שסגורים כרגע מוצגים באופן מובהק כ-"סגור כרגע" עם 0% עומס וללא סתירות.
- **סינון גמיש לפי מרחק (0-40 ק"מ)**: סליידר מרחק אינטואיטיבי המאפשר לסנן במדויק מקומות קרובים בלחיצה על המפה או חיפוש כתובת.
- **חיפוש כתובות וערים**: מנוע חיפוש רב-ערוצי לכתובות, שמות מקומות וערים ברחבי הארץ.
- **סינוני דירוג וטווח מחירים**: סליידרים מהירים לסינון לפי דירוג כוכבים (3.0 עד 5.0) וטווח מחירים.
- **תאימות מלאה למובייל ודסקטופ**: ממשק רספונסיבי מהיר, מודרני ונקי ללא פיצ'רים מיותרים.

## 🚀 התקנה והרצה מקומית (Getting Started)

### דרישות קדם
- Node.js (גרסה 18 ומעלה)
- npm או pnpm / yarn

### התקנה
```bash
git clone https://github.com/natiBirhauz/Open.git
cd Open
npm install
```

### הרצה מקומית לפיתוח
```bash
npm run dev
```
האפליקציה תעלה בכתובת: `http://localhost:5173/`

### בניית גרסת ייצור (Production Build)
```bash
npm run build
```

## 🛠️ טכנולוגיות (Tech Stack)

- **React 19**
- **Vite 8**
- **Leaflet & React-Leaflet** - מפות אינטראקטיביות ו-Clustering
- **Lucide React** - אייקונים מודרניים
- **Canvas Confetti** - אפקטים ויזואליים
- **Vanilla CSS** - עיצוב יוקרתי, אנימציות חלקות ו-Dark Theme מלא
